實際 ToolContract 程式碼

    "get_entity_month_table": ToolContract(
        tool_name="get_entity_month_table",
        description="List all entities for one explicit month and metric.",
        allowed_task_families=("entity_month_table_lookup", "cross_section_compare"),
        required_args=("entity_dimension", "metric", "month"),
        optional_args=("dimension", "parent_filter", "include_qty"),
        supported_entity_dimensions=COMMON_ENTITY_DIMENSIONS,
        supported_metrics=("revenue_amount", "inventory_amount", "inventory_qty"),
        supports_month=True,
        supports_parent_filter=True,
        output_evidence_type="entity_month_table",
        mcp_exposable=True, mcp_name="get_entity_month_table", evidence_roles=("primary",),
    ),

description 是給 planner 的用途描述。

required_args / optional_args 會合併成 allowed arguments。

supported_metrics 與 allowed_task_families 決定這個工具能回答哪些問題。

output_evidence_type 是 Evidence Validator 判斷證據的核心欄位。

read_only / risk_level / mcp_exposable 決定是否能被 MCP 對外公開。

MCP Tool 子集合

  • get_entity_month_table：列出某個月份中各事業群或產品線的一個 KPI 數值。
  • get_entity_metric_ranking：依指定 KPI 排出事業群或產品線名次。
  • get_entity_performance_snapshot：產生實體表現快照，包含營收、庫存與 proxy 分數。
  • get_overall_time_series：查整體 KPI 的月度趨勢。
  • get_revenue_inventory_relationship：找營收與庫存是否出現同向、背離或壓力訊號。
  • get_data_coverage：回報可用月份、資料列數與支援 domain。

MCP 只公開 registry 中 mcp_exposable=true、read_only=true、risk_level=low 的工具。mcp_server/security.py 會拒絕 hidden tool、未知參數、缺少 required args、不合法月份、不合法 dimension/metric、top_n 超過 row cap、以及像檔案路徑的 unsafe argument。MCP 是外部 Agent 的受控入口，不是一般 Dashboard 問答的必經路徑。

新增 Tool 的七步摘要

  1. 實作分析函式
  2. 登記 Tool Contract
  3. 定義 evidence type
  4. 設定 task family 與 metric
  5. 決定是否對 MCP 開放
  6. 新增 focused tests
  7. 執行 validation 與 evaluation gate
