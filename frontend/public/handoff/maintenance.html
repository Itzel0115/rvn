配方一：新增分析工具（Tool）

當既有 Tool 無法取得某種受控分析結果時，才新增 Tool。不要把自由 Python、SQL 或任意檔案讀取包成 Tool。

  1. 在 analysis_tools.py 加一個明確、read-only、JSON-safe 的 method。
  2. 在 tool_registry.py 登記 ToolContract，列出 allowed arguments、supported metrics、task families 與 evidence type。
  3. 確認 plan_validator.py 能用 ToolContract 檢查這個 call。
  4. 決定是否 MCP exposable；預設不要公開，除非參數和輸出都能安全控管。
  5. 補 focused tests，再跑 handoff validator 與相關 evaluation gate。

不能破壞的契約
  • Tool result 必須 JSON-safe。
  • 不要回傳未 redaction 的 raw trace 或真實敏感資料。
  • 沒有 primary evidence 時，不要讓回答看起來完整。
  • MCP Tool 必須通過 allowlist、argument validation、row cap 與 sanitization。

配方二：新增 KPI

新增 KPI 不是只加一個欄位名稱。你要同時確認資料有來源、維度能相容、Tool 支援查詢，以及回答證據規則知道怎麼驗證它。

{
  "metric_id": "revenue_inventory_amount_ratio",
  "display_name_zh": "營收庫存金額比",
  "category": "relationship",
  "semantic_type": "ratio",
  "supported_dimensions": [
    "business_group",
    "product_line"
  ],
  "proxy_warning": "這是描述性 proxy，不是正式 turnover。"
}

來源：semantic_layer/definitions/metrics.json（簡化示意碼）　位置：metric definition　看法：看 metric id、中文名稱、語意類型、可用維度與 proxy 限制如何寫清楚。

  • 資料與計算：確認 data_loader.py / real_data.py 能產生需要的欄位或計算。
  • Tool 支援：把 metric 加到相關 ToolContract 的 supported metrics。
  • 證據需求：若 KPI 會改變回答條件，更新 task_evidence.json。
  • 回答格式：需要 proxy warning 時，Writer Validator 不能把它寫成正式財務結論。
最少測試
uv run pytest tests/test_semantic_catalog.py tests/test_semantic_validation.py tests/test_tool_registry.py

配方三：新增問題類型

問題類型（task family）決定系統如何理解問題、需要哪些證據、可以用哪些 Tool，以及證據不足時要補問、重新規劃或標示 capability gap。

  • Detection：在 TaskProfile / Canonical Task 補上辨識規則。
  • AnswerPlan：定義允許的 Tool、metric、維度與 evidence requirement。
  • Partial / Unsupported：沒有合法 Tool 時應回 capability gap，不要硬湊答案。
  • Tests：補 detection、plan validation、evidence validation 與 writer validation。

進階修改

MCP Exposure

先確認 Tool 是 read-only、參數可完整驗證、輸出可 sanitization 且有 row cap。再同步 tool_registry.py 與 mcp_server/server.py。

Proactive Detector

新增偵測規則後，要讓 Candidate、Investigation、Draft、Approval 都能留下可追蹤 artifact；不能繞過人工核准。

Evaluation Gate

修改 evaluation/policies/regression_gate.v1.json 前，要確認 threshold 是正式門檻，不是為了讓一次結果過關而放寬。
